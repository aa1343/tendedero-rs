# Tendedero for Windows (Rust 轻量版)

> 一个轻量、极致跟手的 **Rust & Tauri 2 重构版本**：
> 截图、剪贴板复制内容以及 **TODO 待办便签** 优雅地悬挂在屏幕顶端的晾衣绳上。
> 鼠标指针在屏幕顶端停留约 0.2 秒（或按下 `Ctrl+Alt+T`），晾衣绳便带着卡片滑下来；移开鼠标或点击空白处，绳子自动缩回并完全穿透鼠标。
>
> 灵感源自 macOS 原版小工具：[**alejandrobujan/tendedero**](https://github.com/alejandrobujan/tendedero)（MIT 协议，作者 Alejandro Buján）。
> 本项目使用纯 **Rust** 从零为 Windows 深度重构，彻底移除了笨重的 Electron 运行时，采用原生 Win32 GDI 截图与轻量级系统 WebView2。

```
                                            ╭─╮ ╭─╮ ╭─╮
   ──●──────────────────────────────────────┴─┴─┴─┴─┴──────────   ← 晾衣绳
   (指针在屏幕顶边停留 0.2 秒或按快捷键 Ctrl+Alt+T 即可滑下)
```

## ✨ 核心特性

| 功能 | 说明 |
|---|---|
| 📸 **原生极速截图** | 按下 `Ctrl+Alt+S`，通过 Win32 GDI 极速捕获全屏并立即晾在绳子上。 |
| 📋 **智能剪贴板收集** | 自动监听复制的图片、文本、网址链接（密码字段等敏感内容自动跳过绝不收集）。 |
| 📝 **全新：TODO 待办便签** | 晾衣绳变身随手便签墙！便签纸上直接打勾（带平滑划线动效与实时保存）、卡片底部回车即加待办、实时统计完成进度条，并提供 5 种马卡龙主题色（`Ctrl+Alt+N`）。 |
| 🗑️ **全新：光标悬停 Del 快速取下** | 光标移到卡片上直接按下键盘 `Del` / `Delete` 键即可随真实物理掉落动效极速取下，支持连续删除与 `Ctrl+Z` 随时多步撤销。 |
| 🧺 **全新：关机自动收纳与生命周期** | 关机/退出时自动将未用图钉固定的卡片收纳至本地 `Archive` 归档并生成直观文本汇总；1天内随时可在本地与搜索框查看找回，超过 3 天自动静默清理。 |
| ⚡ **全新：零迟滞移开即缩回** | 彻底移除延时等待，鼠标移开卡片区域 40ms 内毫秒级瞬间缩回晾衣绳，并秒级恢复全屏鼠标穿透，极致跟手毫无等待感。 |
| 🚀 **全新：开机自启动控制** | 托盘图标右键菜单原生勾选开关。基于 Windows 规范的 `HKCU\...\Run` 注册表标准，纯绿色、零残留、开机静默无黑窗启动。 |
| 👻 **零遮挡智能鼠标穿透** | 收拢在屏幕顶部时 **100% 鼠标完全穿透**（`WS_EX_TRANSPARENT`），点击浏览器标签、窗口标题栏、桌面图标毫无阻碍。 |
| 🔍 **绳上全局搜索** | 按下 `Ctrl+Alt+F` 快速检索绳上的所有文字卡片、链接与待办事项。 |
| 📌 **固定与撤销保护** | 固定（Pin）的卡片永不被自动清理；按 `Ctrl+Z` 可随时撤销刚才的取下操作（支持多步还原）。 |
| 🔒 **纯本地离线隐私** | 零数据上传、零分析埋点、零网络权限，所有数据 100% 严格保存在本机。 |

## ⌨️ 全局快捷键指南

| 快捷键 | 作用 |
|---|---|
| `Ctrl+Alt+T` | **展开 / 收起晾衣绳**（随时一键滑下或缩回） |
| `Ctrl+Alt+N` | **新建待办便签** 并直接挂上晾衣绳 |
| `Ctrl+Alt+S` | **立即全屏截图** 并挂上晾衣绳 |
| `Ctrl+Alt+F` | **在绳上搜索**（支持待办、文本和链接） |
| `Ctrl+Z` | **撤销取下**（恢复刚才删除的卡片或便签） |
| `Del` (悬停时) | **快速取下** 当前鼠标所指的卡片 |
| `Esc` | 关闭搜索/编辑弹窗或收起晾衣绳 |

## 👆 卡片交互手势

- **单击卡片**：复制内容到系统剪贴板（图片复制图像本身，便签与文字复制文本），并弹出气泡提示。
- **双击卡片**：打开卡片（链接开浏览器，图片用默认查看器打开，便签打开深度编辑弹窗）。
- **右上角图钉**：固定/取消固定（固定的卡片永不被自动清理策略清理）。
- **左上角叉号**：取下卡片移入回收站（按 `Ctrl+Z` 随时撤销恢复）。
- **便签打勾**：直接点击便签上的复选框完成任务，实时更新底部进度条。
- **点击空白处 / 移开鼠标**：点击空白桌面或向下移开鼠标超过 0.4 秒，晾衣绳平滑收回并秒级恢复鼠标穿透。

## 🎯 深度便签系统详解

晾衣绳不再只是临时收集框，更是你的桌面常驻便签板：

1. **5 色便签纸质感**：提供黄色、绿色、蓝色、粉色、紫色 5 种便签纸质感与逼真木夹子。
2. **快捷输入行**：便签卡片底部自带快捷输入框，输入任务按回车立即添加。
3. **实时进度条**：卡片底部直观显示完成度（如 `2/3 已完成 (66%)`）。
4. **双击深度编辑**：双击便签卡片呼出完整弹窗，支持更改标题、切换底色、删除或整理条目。

## 🚀 怎么运行

### 便携包（推荐，解压即用）
从 [Releases 页面](https://github.com/aa1343/tendedero-rs/releases) 下载最新便携压缩包：
1. 解压压缩包到任意本地文件夹；
2. 双击 **`Start Tendedero.vbs`**（静默后台启动，完全无黑窗）或 `tendedero-rs.exe`；
3. 晾衣绳会平滑滑下展现就绪，随后静默收起至屏幕顶部；
4. 鼠标推到**屏幕最顶边**停留 0.2 秒，或随时按 **`Ctrl+Alt+T`** 即可唤出！

### 从源码编译构建
确保本机已配置 Rust 开发环境（`cargo`）：
```powershell
git clone https://github.com/aa1343/tendedero-rs.git
cd tendedero-rs

# 编译优化版本
cargo build --release
```
编译生成的单一独立可执行文件位于 `target/release/tendedero-rs.exe`（单文件仅约 9.8 MB）。

## 📂 数据保存在哪里

所有数据均保存在本地目录 `%APPDATA%\tendedero-rs\`（右键托盘图标点击「打开数据存储目录」直达）：

| 路径 | 内容 |
|---|---|
| `Screenshots/` | 原生全屏截图与剪贴板捕获图片 |
| `Notes/` | 自动收集的文字片段与链接 |
| `Todos/` | 待办便签的各项条目与属性 |
| `Trash/` | 取下的卡片与便签（支持 `Ctrl+Z` 撤销） |
| `cards.json` | 绳上所有卡片的元数据索引 |
| `settings.json` | 偏好设置与状态 |

卸载只需直接删除程序目录以及 `%APPDATA%\tendedero-rs\` 即可，无后台常驻服务、无驱动、无多余注册表项。
